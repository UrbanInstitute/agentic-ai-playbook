# Responsible Agentic AI Playbook Example Materials

This subfolder contains examples pulled from real Urban Institute project work in which the team built and/or evaluated AI agents. In certain cases, the information has been edited to enable it to be made publicly available.

In addition to examples uploaded directly to this subfolder, we also link to other useful public repositories below that may be useful.
